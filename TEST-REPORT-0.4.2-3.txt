   Qt 6 development SDK is not installed in this build environment, so the Qt executable was not compiled here.
   The Debian package declares qt6-base-dev and qt6-svg-dev and configures CMake with ATENA_REQUIRE_UI=ON.
   Therefore package installation fails explicitly rather than leaving a UI-only/partial installation if Qt cannot be built.
